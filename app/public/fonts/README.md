# Pixel fonts

Each folder here holds one pixel font as JSON, plus its licence.

The format, the import scripts, and the rules for adding a font are documented
in [docs/fonts.md](../../../docs/fonts.md).

Every font is a third-party work under its own licence, kept in
`<font-id>/LICENSE`. They are **not** covered by the project's MIT licence.
The full list with authors is in the Thanks section of the
[README](../../../README.md).
