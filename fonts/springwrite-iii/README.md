# Springwrite-III

Source: https://opengameart.org/content/springwrite-iii-8x8-pixel-font

Notes:
- Sprite sheet is 8x8 in a 7x14 grid (98 cells).
- Charset is assumed to be ASCII 0x20–0x7E (95 glyphs) in grid order.
- The final 3 cells are unused due to unknown mapping.
